📤 Upload Student Fee Records

Upload an Excel (.xlsx) file to add or update semester-wise fee records for all students. Existing records for the same student + semester + year will be updated automatically.

📊

Click here or drag & drop your .xlsx file

Max size: 10 MB

📋 Required Excel Format

Row 1 must be a header row (it will be skipped). Data starts from row 2.

Column Header Name Description Example
A Roll Number 7-digit student roll number (must be registered) 2201234
B Academic Year Year range in format YYYY-YYYY 2025-2026
C Semester Semester number (1 to 8) 3
D Total Fees Total fee amount for the semester (in ₹) 75000
E Minimum Due Minimum amount the student must pay this semester 37500
F Amount Paid How much has been paid so far (0 if not paid) 20000
⚠️ Important: The Roll Number in column A must match a student already registered in the system. Unknown roll numbers will be skipped and counted in the report.
